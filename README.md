# Tizen TV Launcher

A minimalist, ad-free, privacy-first home launcher for Samsung Smart TVs running Tizen OS.

Features:
- **Apple TV 4K Aerial Video Screensavers**: Official high-definition Aerial video streams direct from Apple's CDN (Greenland fjords, London at night, Hawaii coast, Los Angeles).
- **Integrated NTS Radio Player**:
  - Live Channel 1 & Live Channel 2 with real-time show metadata & broadcast descriptions.
  - 16-detent rotary dial cycling through all 16 NTS Infinite Mixtapes (*Poolside, Slow Focus, Low Key, Expansions, etc.*).
- **Live Local Weather & Clock**: Ultra-clean Swiss typography clock, day/date, and live weather conditions from Open-Meteo (zero API keys, zero tracking).
- **Dynamic App Shelf**: Instant D-pad launch for **Netflix**, **Stremio**, **Apple TV**, **Spotify**, and **Switch 2 (HDMI 2)**.
- **Ambient Screensaver Mode**: Automatically hides all buttons, chassis, and shelves when idle or playing music, leaving pure cinematic scenery.

---

## Installation via TizenBrew

1. Open **TizenBrew** on your Samsung TV.
2. Navigate to **Module Manager** (or click **Add Module**).
3. Enter the GitHub repository:
   ```
   goncalopereira/tizentvlauncher
   ```
4. Select **Install**.

The launcher will now appear as an installed native full-screen application.

## Remote Control Shortcuts

| Button | Action |
| --- | --- |
| `←` / `→` (Left / Right) | Select app / Turn rotary mixtape dial |
| `↑` / `↓` (Up / Down) | Move between App Shelf and Radio Player |
| `OK` / Select | Launch selected app / Play-Pause radio |
| `1` | Jump to NTS Live 1 |
| `2` | Jump to NTS Live 2 |
| `A` | Cycle Apple TV Aerial Video |
| `S` | Toggle Screensaver Mode |
